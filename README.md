# GOJO-SAT0RU - 呪術廻戦 Visualizer

**Created by geniusinsanity** | WITH A LITTLE HELP BY **Google Gemini 3**

A real-time, gesture-controlled **Jujutsu Kaisen** Cursed Technique visualizer running directly in your browser. Built with **Three.js** for particle physics and **MediaPipe** for hand tracking.

![Demo Screenshot](PLACEHOLDER_LINK_HERE)

## 🌟 Features

Experience Satoru Gojo's abilities with interactive particle systems turned on by simple hand gestures.

*   **Cursed Technique Lapse: Blue (蒼)**
    *   **Effect:** A chaotic sphere of attractive force (Implosion). Pulsating electric blue particles.
    *   **Trigger:** **Open Hand** Open Hand (All fingers up).
    *   **Visuals:** Cyan/Blue lighting.

*   **Cursed Technique Reversal: Red (赫)**
    *   **Effect:** A violent, jagged core of repulsive force.
    *   **Trigger:** **Index Finger Up** Index finger up.
    *   **Visuals:** Crimson Red lighting.

*   **Secret Technique: Hollow Purple (茈)**
    *   **Effect:** The collision of Blue and Red, creating an imaginary mass.
    *   **Trigger:** **Pinch** Pinch (Thumb + Index).
    *   **Visuals:** Deep Purple lighting.

*   **Domain Expansion: Infinite Void (無量空処)**
    *   **Effect:** A celestial domain of infinite information.
    *   **Trigger:** **Peace Sign**Peace Sign (Index + Middle).
    *   **Visuals:** White/Silver lighting.

## 🎮 Controls

*   **Move**: Move your hand to guide the technique. The effect follows your movement.
*   **Orbit**: Hold still to see the effect gently orbit and "breathe".
*   **Stop**: Remove hands from view to freeze the effect (Neutral State).

## 🚀 Getting Started

### Prerequisites
*   A modern web browser (Edge, Chrome, Firefox).
*   A webcam.

### Installation
1.  **Clone the repository**
    ```bash
    git clone https://github.com/geniusinsanity/GOJO-SAT0RU.git
    cd GOJO-SAT0RU
    ```

2.  **Add Your Own Images**
    *   Take screenshots of the effects.
    *   Save them in a folder (e.g., `assets/`).
    *   Update this README with the paths (see below).

3.  **Run locally**
    *   **VS Code:** Use "Live Server".
    *   **Python:** `python -m http.server`
